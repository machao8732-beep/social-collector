隐私政策 · 社媒采集器（Social Media Collector）

最后更新：2026 年 9 月 22 日
适用版本：2.2.0 及以后

一句话概括：社媒采集器不收集、不上传、不共享你的任何数据。

所有采集到的内容只存在你自己的浏览器里，扩展不与任何开发者服务器通信——因为它根本没有服务器。

1. 我们收集什么数据

答：不收集。

本扩展没有开发者运营的服务器，也没有任何数据上报通道。我们无法看到你：

  • 采集了哪些视频、回答或评论
  • 你的浏览记录、搜索关键词
  • 你的账号信息、登录状态
  • 任何设备标识、位置信息

扩展中不存在统计 SDK、崩溃上报、埋点或广告组件。

2. 数据存在哪里

所有数据仅保存在你本机的浏览器存储中（chrome.storage.local），包括：

数据存放位置说明
采集到的内容记录本机浏览器存储标题、作者、播放量、正文、评论等
收藏置顶标记本机浏览器存储你手动标记的条目
本机 Agent 接管配置本机浏览器存储开关状态与端口号

这些数据：

  • 不会上传到互联网上的任何服务器
  • 不会在你未操作时离开你的设备
  • 卸载扩展时会被浏览器一并清除

你可以随时在扩展界面里删除单条记录，或点「清空」删除全部。

3. 扩展会访问哪些网站，为什么

扩展仅在你打开下列网站时于页面内运行，目的是把页面上你本来就能看到的内容整理成结构化列表：

网站用途
B 站（bilibili.com）采集视频信息、字幕、评论
抖音（www.douyin.com、creator.douyin.com）采集评论、算数指数数据
知乎（www.zhihu.com）采集问题页下的回答
本机回环地址（127.0.0.1 / localhost）供你本机的 Agent 程序接管（可选）

重要说明：

  • 扩展访问这些接口时，使用的是你浏览器里已有的登录状态（和你自己打开网页看到的完全一样），不会额外申请、存储或外传你的账号凭据。
  • 请求只发往上述平台的官方域名。扩展不会把你的数据转发到任何第三方地址。
  • 页面数据的中转转发（如 B 站字幕）被硬编码限制在该平台域名内，不会成为任意网站的请求跳板。

4. 关于「本机 Agent 接管」功能

这是本扩展的可选功能：让你自己电脑上运行的 Agent 程序（如 OpenClaw、WorkBuddy）调用扩展的采集能力。

  • 该功能默认关闭，需你手动打开开关
  • 连接目标是 ws://127.0.0.1（本机回环地址），即数据只在你自己的电脑内部流转，不出本机
  • 任何外部程序想接入，都必须经过你手动批准（三步配对审批流程），你可随时撤销授权
  • 扩展不会主动向外网发起连接

如果你不使用这个功能，完全可以不开——其余功能不受影响。

5. 我们不会做的事

明确承诺，本扩展绝不：

  • ❌ 将你的数据出售、出租或分享给任何第三方
  • ❌ 用于广告投放、用户画像或行为分析
  • ❌ 收集你访问的与本扩展功能无关的网站
  • ❌ 在你不知情的情况下于后台传输数据
  • ❌ 使用你的数据训练任何模型

6. 你的控制权

你对自己的数据有完全控制：

  • 查看：所有采集内容都在扩展界面里可见
  • 删除：可单条删除，或一键清空全部
  • 导出：可导出为 CSV / Excel / JSON / Markdown，文件保存在你本机
  • 彻底清除：卸载扩展即可清除全部本地数据

7. 权限说明

扩展申请的权限及用途，均遵循最小必要原则：

权限用途
storage在本机保存你采集的内容
activeTab在你主动操作时读取当前页面
alarms维持后台任务与连接保活
sidePanel提供侧边栏界面

8. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童信息（事实上不收集任何人的信息）。

9. 政策变更

若本政策有更新，我们会修改本页顶部的「最后更新」日期，并在扩展更新日志中说明。由于扩展不收集数据，政策变更通常只涉及功能描述的文字调整。
